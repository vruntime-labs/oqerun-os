# Oqerun OS

> The Web, Reimagined as an Operating System.

Oqerun OS is an open-source, browser-native operating system built with TypeScript, HTML, CSS, and WebAssembly.

## Features

- Kernel-first architecture
- Virtual File System
- Process Manager
- Window Manager
- WebAssembly Runtime
- PWA support
