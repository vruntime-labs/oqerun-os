# Security Policy

## Reporting a vulnerability

Please do not publish exploitable details in a public issue or discussion.

1. Open this repository's **Security** tab and use **Report a vulnerability** / private vulnerability reporting if it is enabled.
2. If private reporting is unavailable, use the maintainer contact method listed on the VRuntime Labs GitHub profile to request a private reporting channel.
3. Include the affected URL or file, impact, reproduction steps, and any relevant logs with secrets removed. Do not send passwords, session cookies, access tokens, or other users' personal data.

## Scope and response

This policy covers the latest default branch and the currently deployed project where maintained by VRuntime Labs. The deployed service may differ from source because of provider settings or environment configuration. There is no guaranteed response time; the maintainer will assess reports as resources allow.

Please allow time to investigate and prepare a fix before disclosing a vulnerability publicly.
