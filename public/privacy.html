Privacy Policy

Effective date: 25 October 2026

This page explains the data handling associated with Oqerun OS, based on the published application code and its intended operation. Hosting providers and third-party services may process technical information under their own policies.

Data handled by the application

  • Browser storage: system preferences, app registry entries, and files may be stored in the browser-based virtual file system on your device.
  • Cloud providers: when you connect a provider such as Google Drive, authorization and file operations are sent to that provider. The provider’s own privacy terms apply.
  • Authentication: the Google Drive integration processes OAuth authorization data and server-side session information. The reviewed callback encrypts refresh tokens and uses a secure, HttpOnly session cookie; this does not eliminate all security risks.
  • Third-party applications: opening a web app may send your IP address and other standard request data to that app’s operator. Apps run under their own origins and privacy policies.
  • Hosting: GitHub Pages and API hosting providers may process technical request metadata and logs.

Storage and deletion

Clearing browser site data can remove local files, settings, and the app registry. Cloud files are managed by the connected provider and must be deleted there. Disconnect cloud access and revoke the application’s permission from your Google Account when you no longer want the integration to have access.

Service providers and external links

Oqerun OS is hosted through GitHub Pages and API endpoints used for optional cloud integrations. Google Drive integration communicates with Google when you choose to connect that provider. Links to third-party sites, repositories, application publishers, and services are governed by their own privacy policies. We do not control those services.

Retention and deletion

Where this application stores information in your browser, you can generally remove it by clearing the relevant site data. This may permanently remove local documents, preferences, or installed-app records. Server-side files, if any, follow the retention described above. Do not submit passwords, session cookies, access tokens, or other secrets unless a feature explicitly requires them and you understand the risks.

Children

This project is not intentionally designed to collect personal information from children. If you believe personal information was submitted inappropriately, contact the maintainer using the project’s GitHub repository. Do not post personal or sensitive details in a public issue.

Changes and contact

This policy may be updated when the application’s data practices change. For questions or privacy requests, use the contact method listed on the VRuntime Labs GitHub profile. Do not include sensitive information in a public issue. A dedicated privacy contact should be published before broad public launch.

This policy is informational and is not a legal opinion. Applicable requirements depend on the operator, audience, jurisdictions, and actual deployment configuration. Have it reviewed for the jurisdictions you serve.
